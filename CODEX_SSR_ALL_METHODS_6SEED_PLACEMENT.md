## Fixed-budget placement protocol (per method, dataset, seed)
Determine `U` = actual native unlabeled-training-loader main optimizer positions per epoch, `L` = native scheduled supervised batch/anchor budget appropriate for this controlled run, from **that method+dataset's canonical as-run 5% protocol**; never hardcode Plain's U/L for other methods. Verify `0<L<=U`. Within a paired method/dataset/backbone/seed group: identical U optimizer positions, L **full-strength** supervised anchors, labeled exposure, training split, main unlabeled batch stream, native L_u terms, model initialization/teacher state, optimizers, EMA/ensemble and meta-update cadence. Only the supervised anchor positions vary. Use these zero-based step sets:
- FRONT: `{0, 1, ..., L-1}`.
- EVEN: `{ floor((j+0.5)*U/L) : j=0..L-1 }`, check uniqueness, exact count and spacing; first compare with existing correct source convention.
- BACK: `{U-L, ..., U-1}`, pure BACK with **no early labeled anchor**.
At all U steps run the original method's unlabeled objective as historically implemented, with exactly the native model/optimizer updates. At non-anchor steps do not consume supervised batches or compute supervised-only branches. At each anchor consume one canonical labeled batch at full original coefficient. Preserve native learning-rate schedules and augmentation configuration. Use separate deterministic RNG streams where practicable to prevent supervised batch draws affecting unlabeled order; record known method-state nondeterminism. Pair seed-specific data split and initial parameter digest across FRONT/EVEN/BACK. No extra epochs, optimizer steps or loss-weight changes. Never touch validation/test examples as supervised or meta-training labels.

**Method-fidelity gates (mandatory):**
- Plain: use its own regression weak-to-strong objective, dataset-specific preprocessing, scheduler/optimizer, not a generic training script.
- TE: keep authentic regression-adapted temporal target/ensemble state and method-specific loop, never replace with Plain. Check that teacher/ensemble updates follow all U positions.
- MT: keep student/EMA teacher update semantics, native supervised/unsupervised terms; counting native already-dense supervised steps does not justify arbitrarily increasing L.
