ESSENTIAL PSEUDO-LABELING SOURCE COLLECTION

Scope: gpu01, gpu02, gpu03, gpu04 and gpu05. This replaces the broad
server_collection_20261117 package for code browsing and version preservation.
Every copied source file is byte-for-byte unchanged and SHA256-verified.

Included: Plain/Uniform, Temporal Ensembling, Mean Teacher, HPL, UCVME,
SimRegMatch, their Reorient implementations, required model/data/I/O helpers,
and canonical frequency/placement/mass/quantity ablation code. Selected
launchers retain their original configuration definitions.

Excluded: results, logs, checkpoints, dataset/manifest data, figures, per-seed
records, virtual environments, queue state, historical operational repair
scripts and repeated identical copies. This is a source collection, not a
claim of portable execution or a new scientific validation.

HOW TO READ THE COLLECTION
  shared/       First stored version of each relative source path.
  variants/     Only genuinely different bytes from named source profiles.
  profiles.json Exact file mapping for every preserved source profile.
  SOURCE_INDEX.csv Original host/path/git commit and SHA256 for each mapping.
  verification.json Scope and static verification results.

IMPORTANT: shared/ is a deduplicated storage tree, NOT a single combined
scientific recipe. Use the named profile mapping to identify the original
files together. Never mix Original/+Reorient or dataset-specific variants.
Snapshot-relative paths are retained even when historical launchers used
absolute campaign paths or imported files from outside their snapshot.
Existing data/manifests/pretrained weights and original environments remain
external. requirements.txt is preserved as recorded, not claimed to be an
exhaustive environment lock. No copied launcher was executed.

All original server files and the earlier local archive remain untouched.
The fresh GitHub branch is based on main, without the large archive commit.

PROFILE GUIDE
  Plain: plain_original_formal, plain_reorient_reference
  Temporal Ensembling: gpu04_core / training/temporal_ensembling_benchmark.py
  Mean Teacher: mt_original_regression, mt_original_utk30, mt_reorient_formal
  HPL: hpl_original_* and hpl_reorient_* (dataset-native variants)
  UCVME: ucvme_gpu05
  SimRegMatch: simregmatch_migrated
  Ablations: gpu04_core and supervision_quantity_control

The recorded git commit is the containing repository checkout observed during
collection, not a claim that a frozen snapshot was generated by that commit.
The exact file SHA256 and original source path identify each copied version.
